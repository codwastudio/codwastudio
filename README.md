# Codwa Studio

Codwa Studio is a digital product studio in Jakarta, Indonesia. We build company profile websites, landing pages, web apps and dashboards for businesses in Indonesia and abroad.

Codwa Studio adalah studio digital berbasis di Jakarta yang membantu bisnis membangun website company profile, landing page, web app, dan dashboard.
